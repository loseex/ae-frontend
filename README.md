# AE Frontend

Frontend-приложение на Vue 3 + Vite + TypeScript.

## Требования

Перед началом работы убедитесь, что на вашем ПК установлены:

- **Node.js** — версия **18.x** или выше (рекомендуется LTS). Проверить: `node -v`
- **pnpm** — рекомендуется в качестве пакетного менеджера (устанавливается глобально: `npm i -g pnpm`). Проверить: `pnpm -v`

> Всё также работает и через `npm` — просто заменяйте команды `pnpm <cmd>` на `npm run <cmd>`, а `pnpm install` на `npm install`.

---

## Установка зависимостей

```bash
# через pnpm (рекомендуется)
pnpm install

# или через npm
npm install
```

---

## Запуск в режиме разработки

Команда запускает **Vite dev-сервер** и **локальный сервер-заглушку** (`server-placeholder/server.js`) параллельно.

```bash
pnpm dev
# или
npm run dev
```

- Vite поднимется на `http://localhost:5173` (по умолчанию).
- Сервер-заглушка запустится на порту, указанном в `server-placeholder/server.js`.

Для остановки нажмите `Ctrl + C` — благодаря флагу `-k` в `concurrently` оба процесса завершатся корректно.

### Запустить только Vite

```bash
pnpm exec vite
# или
npx vite
```

### Запустить только сервер-заглушку

```bash
pnpm dev:server
# или
npm run dev:server
```

---

## Сборка проекта

Команда сначала запускает проверку типов через `vue-tsc`, затем собирает продакшн-бандл через `vite build`.

```bash
pnpm build
# или
npm run build
```

Результат сборки — в папке `dist/`.

---

## Предпросмотр собранного проекта

Запускает `vite preview` (статический сервер для `dist/`) и параллельно сервер-заглушку.

```bash
pnpm preview
# или
npm run preview
```

> ⚠️ Перед запуском `preview` убедитесь, что проект уже собран командой `pnpm build`.

---

## Все скрипты

| Скрипт       | Описание                                                        |
| ------------ | --------------------------------------------------------------- |
| `dev`        | Запуск Vite dev-сервера и сервера-заглушки параллельно          |
| `dev:server` | Запуск только сервера-заглушки (`server-placeholder/server.js`) |
| `build`      | Проверка типов (`vue-tsc`) и продакшн-сборка (`vite build`)     |
| `preview`    | Предпросмотр собранной сборки + сервер-заглушка параллельно     |

---

## Стек

- **Vue 3** (`^3.5`) + **Vue Router** (`^5.3`)
- **Pinia** — стейт-менеджмент
- **TanStack Vue Query** и **TanStack Vue Form**
- **Axios** — HTTP-клиент
- **Vite** + **TypeScript** + **vue-tsc**
- **concurrently** — параллельный запуск процессов
